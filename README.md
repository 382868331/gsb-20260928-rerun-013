# 数字电路设计平台

事件驱动的数字逻辑仿真平台：Python(FastAPI) 仿真后端 + React(Vite) 图形前端。
板级布局为后续阶段预留，当前实现逻辑元件连线、事件驱动仿真与波形查看。

## 特性

- 逻辑元件：AND/OR/XOR/NAND/NOR/XNOR/NOT/BUF、输入源、输出探针；每个元件有传播延迟。
- 连线为事件传输线，各自有独立延迟；不同延迟的连线在各自时刻到达，不做静态合并计算。
- 用户可编辑输入激励（`时间:值`，如 `0:0 20:1 60:0`）或一键加翻转，重跑后查看 0/1/X/E 波形。
- 反馈电路：事件队列自然耗尽判为**稳定**；超过仿真窗口仍持续翻转判为**持续振荡**（零延迟环同样可检测，不会挂死）。
- 断开连线 → 输入悬空显示 X（未知）；多个输出驱动同一引脚且电平冲突 → E（争用），冲突解除后恢复。
- 四个内置例子：全加器（组合逻辑）、SR 锁存器（反馈稳定）、环形振荡器（持续振荡）、争用与未知。
- 电路可保存/重新打开/删除（JSON 持久化在 `backend/circuits/`）。
- 每次运行都是全新事件队列：前端按运行序号丢弃过期响应，电路一改动波形即标记「已过期」，旧结果不会混入。

## 启动

后端：

```bash
cd backend
../.venv/bin/python -m uvicorn main:app --reload --port 8000
```

前端：

```bash
cd frontend
npx vite
```

浏览器打开 http://localhost:5173 （Vite 已配置 /api 代理到 8000）。

## 测试

```bash
cd backend && ../.venv/bin/python -m pytest tests/ -q
```

覆盖：传播延迟时序、不同线延迟不合并、争用 E、悬空 X、断线未知、SR 锁存器稳定保持、
环形振荡器判定、全加器真值事件核对、多次运行相互隔离、零延迟环不挂死。
