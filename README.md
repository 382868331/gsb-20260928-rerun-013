# 数字电路设计平台

Python 标准库提供事件驱动仿真和电路持久化，React + Vite 提供逻辑元件连线界面、输入事件编辑、波形和诊断显示。

## 启动

```bash
cd backend
python3 app.py
```

```bash
cd frontend
npm install
npm run dev
```

打开 Vite 输出的地址（默认 `http://localhost:5173`）。

## 已实现

- 元件：`INPUT`、`NOT`、`BUFFER`、`AND`、`OR`、`XOR`、`NAND`、`NOR`、`XNOR`。
- 每个逻辑元件有独立传播延迟；仿真使用按时间排序的事件队列，不做一次性静态求值。
- 支持反馈环；队列清空为稳定，观测窗口后仍有未来事件为持续振荡。
- 未连接输入按 `X` 传播；多个输出连接到同一输入端口发生争用并显示诊断。
- 内置组合延迟、NAND 锁存器、NOT 振荡器、断连/争用示例。
- 电路和多个带版本的输入激励方案保存到 `backend/circuits.json`，可重新载入并重新运行。
- 每份仿真结果拆分电路、激励与组合指纹（忽略画布坐标，覆盖门、连接、方案初值、跳变与观测窗口）；迟到的旧计算只能写回自己的组合，不能改变当前诊断、事件或稳定状态。
- 支持撤销/重做（Ctrl+Z / Ctrl+Shift+Z）；切换示例、连续切换、撤销或保存重开后，结果始终标明所属指纹。
- 可把任意一次运行保存为对照基线，修改单个门延迟或一条连接后重新运行，波形以实线/虚线叠加，并列出各节点跳变时刻与传播延迟差异；稳定、振荡、争用与断连诊断按各自修订分别显示。
- 激励方案支持明确生效时刻、单个输入多次跳变和多个输入同刻变化；可复制方案只改一次跳变，比较首次输出差异，并查看差异发生前的输入变化。
